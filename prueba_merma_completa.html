🧪 Prueba: Cálculo Correcto de Merma Total

📦 Ejemplo: BOLSA FLOW PACK BOQUILLA SAN MIGUEL (Código SIESA: 5948094)

❌ Problema Actual

El modal de trazabilidad solo suma las mermas del producto terminado final (sellado), pero NO suma las mermas de los procesos intermedios (extrusión, impresión, refilado) que NO tienen código SIESA porque son producto en proceso.

Reportes de ejemplo (simplificado):

Proceso Máquina SIESA Referencia Producción Merma (kg)
Extrusión Extrusora 2 — FLOW PACK SAN MIGUEL 770 kg 40 kg
Impresión Impresora — FLOW PACK SAN MIGUEL 360 kg 15 kg
Refilado Refiladora — FLOW PACK SAN MIGUEL 302 kg 47 kg
Sellado (PT) Selladora 1 5948094 FLOW PACK SAN MIGUEL 20,000 und 6 kg

🔴 Cálculo ACTUAL (incorrecto):

const totalMerma = rows.reduce((s,r)=>s+sumNumeros(r.mermasCantidad),0);

Donde rows = reports.filter(r=>(r.siesa===siesa||r.sku===siesa))

Resultado: Solo suma el reporte con SIESA = 5948094 (sellado)
Merma total mostrada: 6 kg ❌

✅ Solución Correcta

Buscar TODOS los reportes relacionados por referencia, incluso los que NO tienen código SIESA (producto en proceso), y sumar TODAS las mermas.

🟢 Cálculo CORRECTO (propuesto):

Paso 1: Obtener la referencia del producto terminado
const ref = rows[0].referencia; // "FLOW PACK SAN MIGUEL"

Paso 2: Buscar TODOS los reportes con esa referencia (con o sin SIESA)
const todosReportes = reports.filter(r => { const refLimpia = (r.referencia||'').trim().toUpperCase(); const buscar = ref.trim().toUpperCase(); return refLimpia === buscar || refLimpia.includes(buscar) || buscar.includes(refLimpia); });

Paso 3: Sumar SOLO las mermas de todos esos reportes
const totalMerma = todosReportes.reduce((s,r)=>s+sumNumeros(r.mermasCantidad),0);

Resultado:
Merma total: 40 + 15 + 47 + 6 = 108 kg ✅

📊 Comparación de Resultados

Método Reportes considerados Merma calculada Estado
ACTUAL 1 (solo sellado) 6 kg ❌ Incorrecto
PROPUESTO 4 (todos los procesos) 108 kg ✅ Correcto

⚙️ Implementación

Cambio en TrazabilidadModal (línea ~1405): 
// ❌ ANTES (solo reportes con SIESA)
const rows = reports.filter(r=>(r.siesa===siesa||r.sku===siesa));
const totalMerma = rows.reduce((s,r)=>s+sumNumeros(r.mermasCantidad),0);

// ✅ DESPUÉS (todos los reportes de la referencia)
const rows = reports.filter(r=>(r.siesa===siesa||r.sku===siesa));
const ref = rows.length ? rows[0].referencia : siesa;

// Buscar TODOS los reportes relacionados por referencia (con o sin SIESA)
const todosRelacionados = reports.filter(r => {
  const refR = (r.referencia||'').trim().toUpperCase();
  const refBuscar = ref.trim().toUpperCase();
  // Match exacto o inclusión parcial para variantes de nombre
  return refR === refBuscar || 
         (refR && refBuscar && (refR.includes(refBuscar) || refBuscar.includes(refR)));
});

// Sumar TODAS las mermas (procesos intermedios + producto terminado)
const totalMerma = todosRelacionados.reduce((s,r)=>s+sumNumeros(r.mermasCantidad),0);

🎯 Resultado Esperado

✅ El modal mostrará:
  • Merma: 108 kg (suma de TODOS los procesos)
  • Reportes: 2 o 4 (dependiendo si solo cuenta PT o todos)
  • Nota: Los "Reportes" pueden seguir mostrando solo los de PT (con SIESA), pero la MERMA debe sumar TODOS

⚠️ Consideración Importante

Los kg producidos NO se suman entre procesos porque cada proceso transforma el material:
  • Extrusión: produce 770 kg de lámina
  • Impresión: consume lámina y produce 360 kg de lámina impresa
  • Refilado: consume lámina impresa y produce 302 kg de lámina doblada
  • Sellado: consume lámina doblada y produce 20,000 bolsas

Pero las MERMAS SÍ se suman porque son pérdidas acumuladas en cada etapa:
40 kg (extrusión) + 15 kg (impresión) + 47 kg (refilado) + 6 kg (sellado) = 108 kg de merma total
